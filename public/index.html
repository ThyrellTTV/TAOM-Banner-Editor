Files, asset folders and atlas naming

Registry and definition paths must stay inside the source module. Other folders may use absolute paths, or paths relative to the module. Game paths are relative to the game folder.

The editor data folder contains caches, backups, drafts, exports and atlas builds. These remain on this computer. Banner masks use the standard 4×4 layout.

Atlas resolution, textures and materials

Saved separately for each mod profile. Applied to future builds; existing source atlases keep their resolution.

BC formats reduce texture memory with some loss of detail. Thumbnail sheets retain transparency and use their packed dimensions; mipmaps stay off for thumbnail sheets.

The template supplies its shader and other material values. Custom settings replace the listed flags; an empty list clears them. Diffuse bindings and existing resource IDs are maintained by the compiler.
